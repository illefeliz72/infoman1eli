-Using MySQL is much better than using simple files because it keeps data organized in one central place. In file-based systems, data gets duplicated, hard to search, and easily corrupted when multiple people use it. MySQL solves this by allowing multiple users to access and update student records safely without losing data integrity.Once real student data is added, the most important DBA responsibility is Security and Access Management. Unlike plain files that anyone can open, a DBA must set up user permissions so only authorized people can view private student records and grades. This protects sensitive data and keeps the database safe.
